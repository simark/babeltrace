== NAME

babeltrace2-list-plugin-providers - List Babeltrace 2 plugin providers and their properties


== SYNOPSIS

[verse]
*babeltrace2* [<<gen-opts,_GENERAL OPTIONS_>>] *list-plugin-providers*


== DESCRIPTION

The `list-plugin-providers` command prints a list of available
Babeltrace{nbsp}2 plugin providers along with their properties.

NOTE: This command lists plugin _providers_. Use the
man:babeltrace2-list-plugins[1] command to list _plugins_.
