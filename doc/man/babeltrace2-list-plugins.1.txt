= babeltrace2-list-plugins(1)
:manpagetype: command
:revdate: 14 September 2019


== NAME

babeltrace2-list-plugins - List Babeltrace 2 plugins and their properties


== SYNOPSIS

[verse]
*babeltrace2* [<<gen-opts,_GENERAL OPTIONS_>>] *list-plugins*


== DESCRIPTION

The `list-plugins` command prints a list of available Babeltrace{nbsp}2
plugins along with their component classes and their properties.

NOTE: This command lists _plugins_. Use the
man:babeltrace2-list-plugin-providers[1] command to list plugin
_providers_.
